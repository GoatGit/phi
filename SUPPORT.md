# Support / 获取帮助

> [中文版本](#获取帮助)

## How to Get Help

PHI is an open-source project maintained by its maintainers. We're happy to help, but please use the right channel so we can respond efficiently.

### Before Asking

1. **Read the [FAQ](README.en.md#faq)** — most common questions are answered there.
2. **Search [existing issues](https://github.com/GoatGit/phi/issues)** (including closed ones) — someone may have had the same question.

### Asking a Question

- **Usage or configuration questions**: [Open a Question issue](https://github.com/GoatGit/phi/issues/new?template=question.yml)
- **General discussion**: use the Question issue template; if Discussions is enabled, you may also use the [discussion area](https://github.com/GoatGit/phi/discussions).

Include your PHI version, OS and architecture, CLI version, and a minimal reproduction. Redact credentials and personal paths from logs and screenshots. Never attach an entire database, OAuth file, or configuration backup.

### Reporting Problems

- **Bug reports**: [Open a Bug Report](https://github.com/GoatGit/phi/issues/new?template=bug_report.yml)
- **Documentation issues**: [Open a Doc Issue](https://github.com/GoatGit/phi/issues/new?template=doc_issue.yml)
- **Security vulnerabilities**: Please do NOT use public issues. See our [Security Policy](./SECURITY.md).

### Feature Requests

- [Submit a Feature Request](https://github.com/GoatGit/phi/issues/new?template=feature_request.yml)
- Please open an issue for discussion before submitting a PR for new features.

# 获取帮助

> [English Version](#support--获取帮助)

## 如何获取帮助

PHI 是一个开源项目。我们很乐意提供帮助，但请使用合适的渠道，以便我们高效响应。

### 提问之前

1. **阅读 [常见问题](README.md#faq)** — 大多数常见问题都已在其中解答。
2. **搜索 [已有的 Issue](https://github.com/GoatGit/phi/issues)**（包括已关闭的） — 可能已经有人问过相同的问题。

### 提问

- **使用或配置问题**：[提交问题 Issue](https://github.com/GoatGit/phi/issues/new?template=question.yml)
- **一般讨论**：使用提问 Issue 模板；如已启用 Discussions，也可使用[讨论区](https://github.com/GoatGit/phi/discussions)。

请提供 PHI 版本、系统与架构、CLI 版本和最小复现步骤。日志与截图请先移除凭据和个人路径，不要上传完整数据库、OAuth 文件或配置备份。

### 报告问题

- **Bug 报告**：[提交 Bug 报告](https://github.com/GoatGit/phi/issues/new?template=bug_report.yml)
- **文档问题**：[提交文档问题](https://github.com/GoatGit/phi/issues/new?template=doc_issue.yml)
- **安全漏洞**：请不要使用公开 Issue。请参阅我们的[安全策略](./SECURITY.md)。

### 功能请求

- [提交功能请求](https://github.com/GoatGit/phi/issues/new?template=feature_request.yml)
- 提交新功能的 PR 之前，请先开 Issue 讨论。
