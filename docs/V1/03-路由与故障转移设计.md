# 03 · 路由与故障转移设计

> 2026-10-13 修订：用户确认将 magpie 的路由组、意图路由、路由状态与数据展示纳入 V1。对照来源和边界见 [10-magpie路由对照与实施.md](10-magpie路由对照与实施.md)。本章区分当前实现与后续设计，不再将意图分类列为 V1 非目标。

## 1. 入口与策略

资源池由 `gateway.rs` 管理，执行器为 `gateway/routing.rs`。原生应用的 provider 队列继续使用原逻辑；资源池请求使用独立的运行状态，不把临时选中的供应商写回 Agent 配置。

- 入口身份来自已认证的应用绑定。组的 `appIds` 与供应商协议必须兼容，不能凭模型名称越过应用范围。
- 2026-10-14 入口简化：应用连接页的连接方式直接选择“直连”或兼容且启用的路由组，取消独立匹配规则板块。选择组后，该应用的普通模型名和已缓存的 `group/<id>` 别名均进入所选组，不再由原匹配规则分流；客户端模型发现只发布所选组。
- 连接选择复用目录中的保留记录 `connection/<appId>`，仅表示一个默认组，不开放模型条件或优先级编辑。旧策略与请求快照继续兼容；尚未选择组的旧连接按原语义读取，显示“旧连接（请选择路由组）”，不会仅因升级修改客户端。
- 组选择和客户端接入在同一应用切换锁内执行，使用目录 `revision` 防止陈旧选择；接入失败恢复此前的连接记录。切换直连恢复原生配置并保留上次组选择。所选组停用或删除后拒绝请求，不自动换组或重新启用旧策略。
- 已有外部认证绑定保留独立的 `group/<id>` 选择与允许组校验；原生应用的默认组不会扩大或重写其授权范围。未指定应用组时，兼容原 `matchModel` / `priority` 策略和直接组调用。
- 每请求读取一份版本化目录；尝试、解释及最终统计使用该快照。保存目录使用 `revision` 乐观锁，旧编辑器不能覆盖新配置。
- 新建供应商复用原有添加供应商页和完整模板；保存到独立资源池后再选择其模型作为组成员。

## 2. 路由组

组设置包含名称、启停、选择策略、成员、故障转移上限和会话保持。成员引用“供应商 + 模型”或另一个组；权重仅在按权重策略下显示。同一供应商的不同模型是不同出口。

2026-10-14 表单简化：不再设置“允许的应用”，保存时按全部成员协议及嵌套组兼容范围的交集自动生成 `appIds`，后端继续校验应用隔离；修改不得破坏已引用此组的策略或上级组。新成员默认启用，不再显示成员开关；旧配置的停用成员保持停用并标注状态，可删除后重新添加。成员以手柄拖动排序，也支持键盘空格开始/确认、方向键移动、Esc 取消；只在保存表单时提交顺序，稳定成员 ID 和规则引用不随排序变化。删除使用带可访问名称的图标按钮。

选择策略只提供顺序、轮询、低用量与权重。旧版手动策略及目标保留，选择其他策略后才转换；表单不再提供手动选择成员。“添加意图规则”入口移除，新组不显示分类模型或空规则区；旧组已有意图规则与分类器置于默认收起的“已有意图规则”，支持编辑、拖动排序和删除，后端继续执行已有规则。删除成员同时清理引用该成员的意图规则。

| 策略 | 选择行为 |
|---|---|
| 顺序 | 按成员顺序选择可用出口 |
| 轮询 | 新请求轮流选择可用成员，预览不消耗位置 |
| 低用量 | 按已知 token 的一小时半衰期衰减值，加活跃请求负载与未知用量请求数排序；不是剩余额度 |
| 权重 | 平滑加权轮询；权重 1–1000 |
| 旧版手动（兼容） | 只选择指定成员；新建/切换策略不再提供此选项 |

组数最多 100，每组成员最多 32，嵌套最多 8 层，候选展开有数量上限。保存时检查循环、悬空引用、模型、协议、应用范围及手动成员。停用成员不参与选择。嵌套组保持自己的策略及尝试上限，父组限制总候选数；重复出口不会重复执行。

`sessionAffinity` 只使用客户端提供的会话标识，按认证应用隔离并存摘要，不猜测会话。一次请求成功完成后建立绑定；配置版本改变、TTL 到期、出口失败或不可用使绑定失效。有效意图命中优先于会话绑定。

## 3. 意图路由（已有配置兼容）

`gateway/intent.rs` 对显式选定的资源池分类供应商发起原生协议请求。规则按用户配置顺序描述条件与目标成员；分类输出只能给出已配置且启用的 `ruleId`，不能提供任意模型、地址或凭据。

- 只发送最新一条用户消息的前 4000 个字符，不发送系统提示、工具结果、图片或思考内容。编辑器明确说明数据去向与额外调用。
- 单个业务请求的所有组共享 6 秒分类时间预算；不跟随重定向，响应体最多 256 KiB。空文本、超时、错误、非法结果或无命中均回到组策略，并保存固定原因类别。
- 命中后优先选择对应成员，故障转移仍受组上限限制。手动策略不调用本组分类模型。
- 分类缓存按应用、会话摘要、目录版本、组及文本摘要隔离，TTL 为 30 分钟。无客户端会话标识时不跨请求缓存；缓存命中没有额外模型费用。
- 请求解释单列分类结果、命中规则、缓存、耗时、已知 token 与估算费用。模型输出不写入日志，分类失败不泄露上游响应体。

## 4. 故障转移和运行状态

每组可关闭故障转移或设置最多 1–11 个出口尝试。限流、鉴权、超时、传输及上游不可用错误触发固定冷却（分别为 60 秒、300 秒、其余 15 秒），下一请求跳过冷却中的出口；这不是主动健康探测或完整的配额预测。

转发沿用现有响应处理边界：只在响应尚未提交时尝试下一出口。流式响应开始后失败或客户端断开记为失败/中断，禁止拼接来自另一出口的响应。运行状态跟踪尝试开始、上游接受、响应完成及中断，不能把收到 HTTP 响应头当作请求成功。

运行状态按供应商和模型记录活跃数、尝试数、完成数、失败数、最近错误、冷却、最近耗时及衰减用量。进程重启后清零。历史统计独立读取已保留的请求记录；未知 usage 保持未知，不以零费用冒充完整结算。

## 5. 请求解释与数据展示

当前持久化模型为 `gateway_traces`，包含策略和组快照、候选及路径、选择时的负载/冷却、意图判断、逐次出口及结果、整体耗时、最终响应已知用量与估算费用。详情使用历史快照，不随当前组名称和排序变化重新计算。请求正文、密钥、原始会话标识不进入轨迹。

控制台仅提供三个标签页，顺序固定为 **应用连接 → 路由策略 → 路由状态**：

1. **应用连接**：应用表格只保留应用、配置目标、连接方式三列。“连接方式”列出直连与兼容且启用的路由组，未配置时显示占位状态；不再提供通用“代理”选项。选择组即保存并接入，配置目标显示组内供应商或嵌套组摘要；“配置”按钮继续进入对应应用的完整配置。所选组不可用时显示状态，并允许改选或恢复直连；尚未接入时显示“待连接”，重新选择该组即可接入；读取失败单独提示重试。网关随 PHI 启动常驻，页头统一显示可用性，端口在设置页修改。
2. **路由策略**：仅配置可复用的路由组，管理成员、嵌套、选择策略、故障转移和会话保持。取消匹配规则列表及编辑器；无副作用请求预览按需展开，不调用分类模型，也不显示匹配优先级。
3. **路由状态**：共用时间窗口、应用、组和结果四个筛选及一个刷新入口，每 5 秒更新。移除匹配规则筛选；后台仍支持旧路由记录的历史查询。请求记录每页 50 条，详情使用请求发生时的组、候选顺序、跳过理由、实际尝试和意图快照。组与出口运行详情按需展开，明确其为进程累计且同一供应商模型跨组共用，不受时间和结果筛选影响。

路由组的“请求记录”操作跳转至路由状态并带入组筛选。供应商的旧路由引用转到历史记录，不再跳转到已移除的匹配规则编辑器。请求解释放在记录详情弹窗中，不另设标签页；统计、筛选和刷新不在各区重复出现。

关闭请求日志时仍更新内存运行状态，但新请求不进入历史报表。数据保留和费用限制以 [05](05-账本与观测设计.md) 的当前实现说明为准。

### 官方 Codex 接入与会话历史

官方 Codex 切换代理无需开启“统一会话历史”。代理期间统一使用 custom 官方镜像，保留原登录，以 x-phi-token 独立认证本地网关；直连时根据原设置恢复 openai 或 custom。会话历史设置不自动修改，已有会话不自动迁移；关闭统一历史时，代理期间新会话属于 custom，与官方直连的 openai 列表仍有区别。

## 6. 保留的后续设计

项目覆盖、基于视觉/上下文/工具能力标签的 `route_rules` DSL、预算闸门、独立的 `route_decisions` / `route_attempts` 权威账本及逐尝试结算仍为后续设计，不能将当前请求快照称为完整账本。这些设计沿用 05/06 的归因、金额精度和失败关闭要求。

本次不引入 magpie 依赖订阅额度窗口/重置时间的 `smart` / `pace`；PHI 资源池尚无相应数据源。学习型、质量评分与预算成本自动路由也未实现。意图规则是用户配置的任务分类，不以无法自动验证的任务质量为前提。

## 7. 验收

- 应用选择组、新建接入、代理中换组、恢复原生配置、接入失败回滚和陈旧目录拒绝；停用/删除所选组不得自动启用其他路由。
- 校验循环、深度、停用、应用隔离、协议不兼容和悬空引用；保存冲突保留编辑内容。
- 顺序/轮询/权重/低用量分配、旧版手动策略兼容、嵌套上限、同供应商不同模型及预览不推进运行状态。
- 自动应用兼容范围、成员拖动/取消/保存与稳定引用；旧停用成员和意图规则不得因表单简化被启用或删除。
- 会话绑定按应用和版本隔离；失败、冷却、TTL 和意图命中正确影响选择。
- 意图模型命中/无命中/非法结果/超时/重定向/缓存均可解释，发送文本范围受限。
- 代理链路记录真实尝试和最终响应；流式中断、日志关闭、进程重启不伪造成功或已知用量。
- 创建资源池供应商 → 建组 → 绑定策略 → 接入 Agent → 查看实时路径与请求解释，全流程可以完成。
