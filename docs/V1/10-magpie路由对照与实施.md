# 10 · magpie 路由对照与实施

本次范围（2026-10-13）：按用户确认，将路由组、组内策略、意图路由、路由状态与数据展示纳入 V1。以 `tmp/magpie` 的实现为行为参考，在 PHI 的 Rust 网关、独立供应商资源池与 React 控制台上实现，不移植 Go 服务或订阅适配器。

## 实施约束

- 路由组与原有应用策略兼容：原策略候选保留，策略可以指向组；客户端可使用 `group/<id>`，仍受组的应用范围与协议兼容校验。
- 嵌套深度、成员数、规则数有上限；循环引用、无效手动选择、悬空引用在保存前拒绝。停用组不能通过直接模型名绕过。
- 意图分类只发送当前用户消息的有限文本给显式选定的分类出口，不转发系统提示、工具结果、图片、密钥；配置页面说明数据去向和额外调用。分类结果只能选择已配置的规则，不接受模型提供的地址或供应商。失败按既定组策略回退并记录原因。
- 不持久化请求正文；保存决策时的组、规则、候选与状态快照，不能用当前配置重算历史。会话只保留命名空间内摘要。
- 实时状态与持久化统计分开；时间窗口、日志是否启用、未知用量、估算费用与分类调用开销均明确展示。缺失值不填零。
- 保留原生配置恢复、入口认证以及流式提交后禁止透明重试的边界。

## 实际代码位置

- `src-tauri/src/gateway/routing.rs`：组校验、各选择策略、候选展开、会话保持、冷却与运行状态；`intent.rs`：有界分类及缓存；`analytics.rs`：筛选、分页和统计。
- `gateway.rs`：版本化目录、共享凭据投影、请求计划与快照；`proxy/handler_context.rs`、`forwarder.rs`、`gateway_observer.rs`：真实尝试、响应完成与中断。
- `proxy/handlers.rs`：组别名与模型发现。Codex 复用已有完整目录模板，保留客户端必需字段；组未配置能力元数据时采用文本输入与默认窗口，不承诺组内模型能力自动求交集。
- `src/components/gateway/GatewayPages.tsx`：仅提供应用连接、路由策略、路由状态三个标签。`GroupSection.tsx` 在策略页管理路由组，匹配规则编辑器已移除；应用连接下拉框直接选择路由组，`RoutePreview.tsx` 提供可展开的无副作用预览。
- `RoutingStatus.tsx` 统一持有状态与历史的筛选、分页及查询，每 5 秒刷新一次；`TraceSection.tsx` 使用同一份结果展示记录，`DecisionDetails.tsx` 展示历史解释。组到请求筛选的跳转保留，旧路由引用进入历史查询，不再返回匹配规则编辑器。
- `RoutingFlow.tsx`、`routingFlowModel.ts` 参考 magpie GUI 的节点与连线，展示选中请求的应用、网关、供应商 / 模型与嵌套组路径。图表共享查询，默认跟随最新活动请求，支持历史选择、逐次尝试回放和定位；按请求结局区分上游接受与实际完成，历史不套用当前配置和健康状态。
- `ResourcePoolSection.tsx`、`AddPoolSupplier.tsx`：继续使用原添加供应商模板；删除供应商时清理成员和分类器引用，停用空组及其空祖先。

## 控制台简化（2026-10-14）

应用连接的“代理”选项替换为兼容且启用的路由组列表，取消匹配规则板块与筛选。选择组生成一个内部默认连接记录，接入失败恢复此前选择，旧规则仅用于兼容与历史；所选组不可用时拒绝请求。组选择、客户端配置重写与直连恢复已纳入同一应用切换锁和目录版本校验。外部认证绑定继续使用其自身允许组范围。

按用户要求，组编辑移除允许应用、手动选择选项、成员开关、上下移动按钮和“添加意图规则”。应用兼容性按成员自动计算；成员与已有规则复用 dnd-kit 手柄拖动及键盘排序，删除使用图标按钮。新组只提供顺序、轮询、低用量与权重。后端仍兼容旧版手动策略、停用成员和意图执行；已有意图设置默认折叠，保存普通字段不会清空既有规则。

## 当前边界

历史最多保留最近 1000 条，窗口筛选只统计保留记录；运行状态按进程生命周期维护。主请求费用取最终响应，分类费用单列；失败尝试尚无完整结算。关闭日志不新增历史记录。权威账本、预算、Keychain 迁移、订阅额度与账号适配器仍按对应章节推进，不把它们标记为此次路由迁移的交付能力。
