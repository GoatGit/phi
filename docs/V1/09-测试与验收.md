## 2. phi 新增测试

### 2.1 协议黄金集（02 §4，最大投入项）

- 录制 + 手工构造 + 上游测试移植三路用例来源；
- 断言：规范化 JSON diff + SSE 事件序列 diff + usage 解析结果 diff；
- 门槛：改 `providers/`、`transform_*`、`streaming_*`、矫正器的 PR 必须有黄金集佐证；M2 出口 ≥120 例全绿。

### 2.2 迁移测试（06 §5）

- v4.0.8 老库 → phi 首启迁移（数据 + 密钥两条线）；全新建库；迁移中断重入；
- 用例库：按冻结 schema 构造全表合成 fixture（含已有 session_id、WAL、profiles 与旧接管备份）；覆盖跨 secret/SQLite 步骤中断、锁库及加密包换机恢复。

### 2.3 适配层幂等与恢复（04 §6）

- 每 Agent：切换 A→B→A 语义等价；一键恢复原生后 Agent 独立可用；
- 外部修改保留：非受管字段修改不被恢复覆盖；受管字段冲突明确提示。覆盖首次即已接管、无可信 baseline、不存在文件、失效凭据和多文件写入中断；
- fixture：各 Agent 真实格式样例（含注释、极端缩进、BOM）。

### 2.4 账本勾稽（05 §6）

- 尝试账本费用 == 请求投影费用 == 各独立维度费用；不同维度不能相加，多账号/模型请求数按 06 §3.1 去重；
- 预算累计按在线归属核对，覆盖重复终结、迟到 usage、未知量、跨 UTC 窗口、并发与长流超支；费用 block 对 UNPRICED 拒绝，warn 展示缺口；
- 共享入口不同 Agent、项目绑定缺失/伪造、事后归因补录不改变在线预算；Token reported 不得被显示为费用 reported。会话导入与代理记录不双计。

### 2.5 安全审计（07 §7）

- 凭据字段/无前缀合成秘密扫描与 AEAD 篡改测试，覆盖库、WAL、快照、迁移临时材料及备份；区分 live 与旧目录的明文边界；
- 所有入口/别名/models/status/流式/WebSocket 的缺失及错误令牌拒绝；官方上游 Authorization 与本地令牌隔离，拒绝直连非回环明文监听；
- 日志脱敏单测（各类认证头/URL key/请求体凭据字段）；
- 更新签名：篡改包必被拒。

### 2.6 嵌入终端（macOS 首版已实现，发布验收待补齐）

按 [12 §7](12-嵌入终端与应用标签页设计.md#7-实施与验收顺序) 验证标签会话保留、CLI 发现与安全启动、启动取消与幂等、原生视图层级、输入法、跨屏缩放及所有退出路径。浏览器原型通过不等于原生终端通过；已完成 22 项真实 PTY/原生视图断言、27 项前端与 12 项后端终端相关测试，并用实际 React 组件检查小窗口和多标签；详细结果见 12 §7.4。真实 CLI 登录、系统 IME 候选框、跨屏、Intel 与签名分发仍需独立验收。

## 4. V1 产品验收标准（M2 出口 / 验证版发放条件）

### 4.1 核心体验（获客承诺）

| # | 指标 | 标准 | 验证方式 |
|---|---|---|---|
| A1 | 新用户接入时长 | Claude Code / Codex / Gemini CLI 任一：安装 → 成功发起首次对话 ≤ **5 分钟** | 验收脚本 + 3 人实测 |
| A2 | 切换成功率 | 10 个 Agent 的 provider 切换成功率 ≥99%（含 A→B→A 往返） | 自动化（适配层测试）+ 人工清单 |
| A3 | 模型目录 | Anthropic / OpenAI(Chat+Responses) / Gemini / Copilot / xAI 全部可用；聚合商自定义 OpenAI 兼容端点可用 | 黄金集 + 真实端点冒烟 |
| A4 | 流式与工具调用 | 主流场景长会话（>30 轮、含工具调用与 Thinking）无流中断、无状态错乱 | 黄金集 + 众测 |
| A5 | 故障转移 | 响应提交前可重试失败完成切换；首帧后断流明确失败且不透明重放；多跳决策完整 | 演练（03 §5）+ 断言 |
| A6 | 反锁定 | 可信 baseline 恢复后独立可用；缺失或冲突明确提示，不覆盖外部修改 | 人工清单全覆盖 |

### 4.2 延伸体验（付费叙事地基）

| # | 指标 | 标准 |
|---|---|---|
| B1 | 归因率 | 项目维度归因 ≥80% |
| B2 | 三元组可查 | 已受理请求有持久化摘要，未知/中断显式展示；故障注入验证落盘失败不转发 |
| B3 | 预算 | 已结算阈值 warn/block 生效；明确披露在途超支，未知费用 block 失败关闭 |
| B4 | 口径诚实 | Token 与费用来源分开标注；价格版本固定，手动校准不篡改明细 |
| B5 | 凭据安全 | phi 管理持久存储无明文凭据；无 keyring 使用口令保险库/会话模式，锁定失败关闭 |

### 4.3 质量门槛

- CI 全绿（三平台）；黄金集 ≥120 例；
- 性能目标：固定硬件、release 构建、本地 mock 上游，预热后每场景至少 1000 请求，分别测并发 1/10/50；比较直连与 phi 的首字节差值（含鉴权和持久化），P95 ≤15ms，记录环境/样本/错误率。万级明细报表目标 ≤1s；未达标须分析，不能用事件序列黄金集代替压测。
- 稳定性：注入 listener task panic 验证有限退避重启；注入进程 kill/abort 验证在途失败、账本 interrupted 和下次启动恢复。两周验证统计真实崩溃及失败率，不把 supervisor 当作进程崩溃无损恢复保证。

## 5. 验证期（10–20 名重度用户 × 两周）观测指标

- 网关日活跃（接管请求数）与自然留存；
- 故障转移触发率与成功率（决策日志直接产出——这也是差异化叙事的实证数据）；
- 账本/报表查看频率；预算功能使用率；
- 质量问题 Top10（按 Agent × 协议组合聚类，黄金集针对性补强）；
- 付费意愿访谈（定价假设：免费核心 + 账本/预算高级能力付费，具体在验证期后定）。

M3 依据以上数据决定 GA / 回调范围 / V1.x 排期（独立网关进程、CLI、Windsurf 适配为既定候选）。
