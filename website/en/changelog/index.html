Changelog

Every release, and what changed in it. The in-app update note links here too.

  1. 1.3.02026-11-25

    • Tasks can resume a chosen agent session and keep working in that conversation; only one card runs a session at a time.
    • Extra agent arguments now cover claude, codex, gemini and opencode, grouped by purpose, and the list scrolls on its own.
    • Approval flags sit in their own group marked as turning approval off; sandbox options only include the stricter read-only mode.

    See all items →

  2. 1.2.02026-11-22

    • The agent view is now a four-column graph: discussion with Lead, Lead, agents, and the focused agent's cards; click a node to focus it.
    • Every task card gets its own ownership wire, and only the running card animates in the accent colour.
    • Three agents ship built in: researcher, product manager and engineer, applied only before any settings exist.

    See all items →

  3. 1.1.02026-11-22

    • The task board gains an agent view: one row per agent, with a discussion row first.
    • Agent definitions now cover who it is, what it owns, what it may use and how done is judged, compiled into the launch prompt.
    • Draft an agent by talking to Router: conversation on the left, definition on the right, any version can be resumed.

    See all items →

  4. 1.0.52026-11-17

    • Task boards gain background checks, schedules, and result artifacts.
    • The plugin center adds lessons, session handoffs, and reliability scorecards.
    • Routing views clarify filters and keep app order stable within each activity tier.

    See all items →

  5. 1.0.42026-10-24

    • Usage pages show third-party app names instead of the built-in app they borrow.
    • Fixed Chat-protocol requests failing on optional fields when routed to Anthropic upstreams.
    • Safety refusals now pass through their reason instead of an empty reply.

    See all items →

  6. 1.0.32026-10-21

    • The Windows installer now ships the subscription engine.
    • The universal macOS build now includes subscriptions on both chips.

    See all items →

  7. 1.0.22026-10-21

    • New subscription engine: sign in once and the account's models join the resource pool for routing.
    • New third-party app access: Command Code, Crush, Droid, Kimi Code, AtomCode and OmO connect with a token; app nodes can reissue or delete it.
    • New System One decision-protocol entry, routed by group.

    See all items →

  8. 1.0.12026-10-19

    • The routing page is one row per app: open a row to set its route or start a group.
    • Route groups can mix models from different protocols, and any app can use them.
    • The sidebar lists every routable app, folding the less-used ones until you need them.

    See all items →

  9. 1.0.02026-10-14

    • PHI 1.0: one local gateway for all your AI coding tools.
    • Manage provider settings for Claude Code, Codex and the rest in one place.
    • Usage gained dedicated session and context panels.

    See all items →
