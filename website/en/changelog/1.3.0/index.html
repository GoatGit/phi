Changelog

1.3.0

2026-11-25
  • Tasks can resume a chosen agent session and keep working in that conversation; only one card runs a session at a time.
  • Extra agent arguments now cover claude, codex, gemini and opencode, grouped by purpose, and the list scrolls on its own.
  • Approval flags sit in their own group marked as turning approval off; sandbox options only include the stricter read-only mode.
  • The agent view's wires now follow scrolling instead of drifting out of place.
  • Artifact paths are now checked against symlinks, so files outside the repository are neither opened nor sized.
  • Multi-line labels and assignees are written as valid YAML instead of making the whole card unreadable.
  • The backlog directory must sit inside the workspace root; paths pointing outside are refused.
  • Settings are written atomically, so a hard quit or power loss no longer clears local preferences.
  • Plugin rule replacements are literal, so $5 is no longer expanded as a capture group; the protocol page and account panel stop showing raw keys.
