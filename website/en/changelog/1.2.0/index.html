Changelog

1.2.0

2026-11-22
  • The agent view is now a four-column graph: discussion with Lead, Lead, agents, and the focused agent's cards; click a node to focus it.
  • Every task card gets its own ownership wire, and only the running card animates in the accent colour.
  • Three agents ship built in: researcher, product manager and engineer, applied only before any settings exist.
  • Agent arguments are now picked from a dropdown that lists the flags actually allowed on the command line.
  • Super Agent is pinned to the sidebar by default, and unpinning it is not undone on restart.
  • The task board is now Super Agent, and Router and the dispatcher are both called Lead.
  • The agent view is the default, with the switch ordered agents first, board second.
  • The task column's actions collapse into four right-aligned icons: enable, edit, delete, plus.
  • The discussion form's submit button is now a bordered button; submitting waits and locks input instead of dropping the form.
