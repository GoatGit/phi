Changelog

1.1.0

2026-11-22
  • The task board gains an agent view: one row per agent, with a discussion row first.
  • Agent definitions now cover who it is, what it owns, what it may use and how done is judged, compiled into the launch prompt.
  • Draft an agent by talking to Router: conversation on the left, definition on the right, any version can be resumed.
  • Agents and Router have avatars that can be changed with one click.
  • Task details can discuss requirements with Router; conclusions are written back and Router's forms can be filled in place.
  • Discussion and execution are exclusive: discussion cards are never dispatched, and finished cards can start a new round.
  • Cards can be assigned to an agent, separately from starting it; dispatches record the agent snapshot.
  • Fixed missing backgrounds on drag targets and suggestion cards caused by unsupported opacity modifiers.
