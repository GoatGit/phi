Three tools, three setups.
You just want to code.

You probably use Claude Code, Codex and Gemini CLI at the same time. Each speaks its own protocol and keeps its own configuration. Changing providers means editing three or four places; changing a route means remembering which file you touched last time.

PHI puts all of this in one window: the gateway translates protocols, route groups assign the line, and the terminal lives in the same app. Set up a provider once and use it across tools. No PHI account; settings and stats stay on your machine, and model access still uses your own account or API key.

An independent fork of CC Switch, built with Tauri 2, Rust and React.

Same-protocol passthrough

When both sides speak the same protocol, requests pass through as they are; streaming, tool calls and usage fields are not rewritten.

Cross-protocol translation

Requests, responses and streaming events are translated to the target protocol; tool calls, reasoning content and token usage are preserved wherever possible.

Four chat protocols

OpenAI Chat Completions, OpenAI Responses, Anthropic Messages and native Gemini. Pick one for the entry point and one for the upstream; they don't have to match.

System One (coming soon)

A decision protocol: the request carries a state and a set of questions, and the reply is structured answers with probabilities. It keeps its own path through the gateway and is never rewritten into a chat request.

System One isn't available yet. Once it ships, it will appear in the provider protocol list. Before a cross-protocol setup, try a simple task to confirm tool calls and streaming. Gemini CLI currently accepts only a native Gemini upstream.

Direct is simple. A route group carries more.

Each app can pin one provider, or put providers and models into a route group and let PHI pick by strategy. Members don't have to share a protocol or a model; the gateway translates as it forwards.

Decision model
A model reads the latest user message, picks one of your rules, and hands the request to that member. The model chooses a rule only; it cannot name a provider or read credentials.

  • Session affinity

    A conversation stays on the same member where possible, so context doesn't move back and forth.

  • Failover

    Matching errors move to the next line; a member that keeps failing cools down and returns when it recovers.

  • Timeouts and retries

    Set limits for first byte, streaming idle time and total time, so a slow line can't hang.

Route groups can nest: a member can be a provider, a model or another group. Direct mode skips the PHI gateway and keeps the app's original connection.

PHI has no project-run cloud backend: configuration, session statistics and the usage ledger live on this machine in ~/.phi/. Subscription OAuth tokens go to the system keychain. Only when you use an online model does the CLI or local gateway connect to your chosen provider.

A few things before you download.

Does PHI include models or free credits?

PHI is an open-source desktop tool and does not include model credits. Bring a provider API key or a subscription account your tool supports; the provider bills for model usage.

What's the difference between direct and a route group?

Direct mode skips the gateway and keeps the app's existing connection to one provider. A route group puts several providers or models together, PHI picks one by strategy, and moves on when one fails. Members can use different protocols.

Where do my keys and requests go?

Main configuration and usage data stay on this machine; subscription OAuth tokens go to the system keychain. Through the local gateway, requests reach PHI first and are then forwarded to the provider you configured; in direct mode the app connects to the provider itself. Either way, request content and the credentials it needs go to the provider you chose.

Are unified sessions and long-term memory available now?

Session browsing works: records the tools keep on this machine land in one list, where you can view them by project or time, search, and copy a resume command. Continuous sessions across tools and long-term memory are still in planning.

Can I run CLIs inside PHI on Windows or Linux?

The built-in terminal currently requires macOS 13 or later. On Windows and Linux, use PHI to manage settings, connect models and track usage, and run CLIs in an external terminal.

How do I update or report a problem?

Choose “Check for updates” in the app, or visit GitHub Releases for the latest version. Report problems on GitHub Issues with your OS version, tool name and steps to reproduce. Remember to remove any keys.
