変更履歴

1.1.0

2026-11-22
  • タスクボードにエージェントビューを追加：1 行 1 エージェント、先頭は Router との相談行です。
  • エージェント定義を「誰か・何を担うか・何を使えるか・完了条件」に拡張し、起動時の指示に組み込みます。
  • Router と対話してエージェントを起草：左に対話、右に定義、任意の版から続けられます。
  • エージェントと Router にアバターを追加し、クリックで変更できます。
  • タスク詳細で Router と要件を相談でき、結論はカードに書き戻され、フォームはその場で入力できます。
  • 相談と実行は排他：相談カードは自動派遣されず、完了カードから新しい相談を派生できます。
  • カードをエージェントに割り当てられ、割り当てと着手は別操作。派遣時のスナップショットを記録します。
  • 透明度指定が効かずドラッグ先と提案カードの背景が欠けていた問題を修正しました。
