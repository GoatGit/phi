为什么会有 PHI

配置这件事，
本来不该这么麻烦。

你可能同时在用 Claude Code、Codex 和 Gemini CLI。每个工具一套配置， 换一家供应商，就要在三四个地方各改一遍；想换个模型，先得翻出上次改的是哪个文件。

PHI 把这些收拢到一处：供应商填一次，几个工具一起用；想跑命令，不用离开应用去找终端。 不需要注册 PHI 账号，配置和统计留在本机；模型服务仍使用你自己的账号或 API Key。

它从 CC Switch 独立开发而来，用 Tauri 2、Rust 和 React 写成。

01内嵌终端

在 PHI 里直接跑 CLI。

应用页右上角的「＋」，或者按一下 ⌘T，选个目录就能启动。 PHI 会检查本机的 CLI 是否已安装，找到后在所选目录启动。 Claude Code、Codex、Gemini CLI 等 9 种工具，都可以这样打开。 目前仅 macOS 13+ 可用；未安装的 CLI 会显示安装提示。

  • 配置和终端，各占一格标签

    同一个应用里来回切，改完供应商不用另开窗口去跑命令。

  • 需要对照，就左右分屏

    同一工具的两个会话并排放：一边改代码，一边检查结果。也可以上下分屏。

  • 配色跟着你走

    跟随 PHI 的浅色／深色，或从几套内置配色里挑一个，换应用也不会丢。

  • 切走了，它还在跑

    去别的页面看用量、改配置，进程不会被打断；回来接着输入就好。

  • CLI 退出，也不黑屏

    回到同一个 shell，工作目录和刚才的输出都还留着。

02本地网关

一个模型，几个工具都能用。

PHI 在本机起了一个网关。Claude Code 说 Claude 的协议，Codex 说 Codex 的， 中间的转换由网关来做。于是同一家供应商、同一个模型，不必为每个工具各接一次。

  • 供应商 A
  • 供应商 B

路由
按应用和请求的模型，把流量送到指定的供应商。
聚合
几家供应商合成一组，主线路失败还有下一条。
故障转移
遇到符合条件的错误，按配置尝试备用线路；持续失败的线路会暂时避开。
直连
不想经过网关，也可以保持工具原来的连接方式。

配置保存在本机。使用模型时，请求内容与所需凭据会发送到你选择的供应商，PHI 不提供模型服务。

03配置

配置写一遍，工具各自认。

供应商、MCP、Skills 和提示词放在一处管理，再按工具支持的方式应用到配置中。

供应商与密钥
多家供应商、多个模型放在一起，切换只要点一下。订阅类登录凭据交给系统钥匙串保管。
MCP 与 Skills
统一的服务器与技能列表，装到哪些工具、有没有生效，一眼能对上。
提示词
常用提示词存成一份库，随时复制，或直接写进项目配置。
项目快照
把当前供应商、MCP、Skills 和记忆文件存成一个项目，工作和个人环境一键切换。
授权中心
哪个账号需要重新登录、哪些是默认账号，集中在一处处理。

04用量

这个月花在哪，心里有数。

会话数、Token、费用、缓存命中、活跃时长，都记在本地账本里。 按天看趋势，或者用星期 × 小时的热力图，看看自己通常什么时候用得最多。

  • 按应用、供应商、模型拆开看

    知道钱花在哪个工具、哪个模型上，而不是只有一个总数。

  • 请求能点开

    每条请求的模型、耗时、Token 与费用都有记录，对不上时能追。

  • 长会话有底

    上下文水位曲线和自动压缩阈值，提醒你什么时候该开新会话。

05本地

数据在哪，说得清楚。

PHI 没有项目方的云端后端。配置、会话统计和用量账本都在本机 ~/.phi/ 里，订阅类 OAuth Token 交给系统钥匙串。 查看本地配置和已有统计不依赖 PHI 云端服务。使用在线模型时，CLI 或本地网关会连接你选择的供应商。

和你已经在用的工具一起工作。

06开始使用

从你熟悉的工具开始。

不用一次配好所有东西。先连通一个工具，再慢慢整理自己的工作台。

  1. 1

    装好 PHI 和你要用的 CLI

    PHI 管理和启动工具，CLI 仍需按其官方说明安装；已有的安装可以继续用。

  2. 2

    添加供应商，选好连接方式

    填入自己的模型服务信息，在「路由」页选择直连供应商或网关路由组。

  3. 3

    打开项目，开始做事

    macOS 13+ 可在应用页点「＋」选目录启动 CLI；其他平台继续使用外部终端。

你可能想问

下载前，再说清几件事。

PHI 自带模型或免费额度吗？

PHI 是开源桌面工具，不提供模型额度。你需要自行准备模型供应商的 API Key 或对应工具支持的订阅账号；模型费用由所选服务商收取。

Windows 和 Linux 也能在应用内运行 CLI 吗？

内嵌终端目前仅适用于 macOS 13 及以上。Windows 和 Linux 可以使用 PHI 管理配置、连接模型和查看用量，CLI 在外部终端运行。

我的密钥和请求会经过哪里？

主要配置与用量数据保存在本机，订阅类 OAuth Token 存入系统钥匙串。调用模型时，请求内容和必要凭据会交给你配置的供应商。请只连接你信任的服务，并妥善保管本机数据。

每个工具都能使用所有模型和功能吗？

具体取决于工具、模型和供应商。网关可以转换支持的协议，但工具调用、上下文长度等能力仍有差异，接入后建议先用一个简单任务确认效果。

如何更新和反馈问题？

在应用内选择「检查更新」，或到 GitHub Releases 获取新版本。遇到问题可以在 GitHub Issues 反馈，附上系统版本、工具名称和复现步骤，记得隐去密钥。

让配置归位，让工作继续

准备好，把工具放在一起。
