§ 01 — CAPABILITIES

一个网关，管好每一件事

从供应商接入到请求路由，从配置管理到费用账本——phi 把 AI 编程工具背后那些琐碎、易错、看不见的部分，变成一台安静运转的本机网关。

i PROVIDERS · PROTOCOLS

模型自由

接入任意 API 供应商与订阅账号，跨协议调用所有模型。官方渠道、第三方中转、自建网关随意组合，不被任何单一生态锁定。

ii ROUTE · FAILOVER

本地路由与故障转移

请求在你的本机路由：协议转换、模型聚合、熔断与故障转移全部在回环地址上完成，延迟不增加，数据不出网。

iii MCP · SKILLS · PROMPTS

统一配置中心

MCP、Skills、提示词与项目配置一处管理，配置版本化、可对比、可回滚。不用再手改 JSON / TOML / YAML。

iv USAGE · COST · BUDGET

请求级账本

Token 用量、费用归因、预算阈值与用量报表，逐请求记录。看清每一个请求由哪个模型处理、花了多少钱。

v GHOSTTY · TERMINAL

内嵌原生终端

CLI 应用页内嵌基于 Ghostty 的原生终端标签页，点击 ＋ 直接启动应用，网关与终端同屏（macOS 13+）。

vi KEYCHAIN · ENCRYPTED

凭据安全

API Key 加密存储，OAuth 令牌交给系统 Keychain。菜单栏面板随时查看额度、路由状态与今日用量。

§ 03 — PHILOSOPHY

本地优先，且完全开源

φ

本地优先

phi 的网关常驻你的电脑，所有请求在回环地址上转发；数据、凭据与请求记录保存在本地 SQLite 数据库，不上传任何遥测。你的模型、你的密钥、你的账单，只属于你。

  • 回环监听 127.0.0.1 · 网关进程内嵌
  • API Key 加密存储 · OAuth 令牌入系统 Keychain
  • 本地 SQLite · 配置版本化 · 可回滚
  • 零遥测 · 零上传 · 无账号要求
