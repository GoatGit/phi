1.0.5

2026-11-17
  • 任务看板支持后台持续巡检、排期和结果产物查看。
  • 插件中心新增教训库、会话接棒和成绩单。
  • 路由图展开与筛选更清楚，同级应用不再随刷新跳位。
  • 修复终端主题继承与多标签横向滚动挤走页头。
  • 后台 worker 使用持久化 zellij 会话；任务可查看结果、产物，并在需要决策时转人工。
  • 任务排期改用日期、时间和间隔控件；一次性排期改时刻后可再触发，取消排期会清理旧起点。
  • 路由页合并供应商入口，新增 MCP 路由管理；Codex 支持 Responses WebSocket 接入。
