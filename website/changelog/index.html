更新日志

每个版本改了什么，都记在这里。应用内更新弹窗的「详情」也会指向这些页面。

  1. 1.3.02026-11-24

    • 任务卡可续接同一仓库的 Claude 或 OpenCode 会话，不必每次重新交代背景。
    • 配置智能体时，按应用挑选追加参数；需要放宽审批的开关单独列出。
    • 改派给不支持续接的智能体后，可在卡片里取消旧会话绑定。

    查看完整条目 →

  2. 1.2.02026-11-22

    • 智能体视图换成四列拓扑图：输入（与 Lead 讨论）、Lead、智能体、聚焦那一支手上的卡；点节点即聚焦。
    • 每张任务卡各有一根归属线，只有正在跑的那张走主题色流动线。
    • 系统默认带三个智能体：文档调研员、产品经理、工程师，只在还没配置过时生效。

    查看完整条目 →

  3. 1.1.02026-11-22

    • 任务看板新增智能体视图：一行一个智能体，第一行是与 Router 的讨论区。
    • 智能体定义扩展为「它是谁、负责什么、能使用什么、怎样算完成」，派发时编译进启动指令。
    • 添加智能体时和 Router 多轮对话起草，左侧对话、右侧定义，任意版本可切回继续聊。

    查看完整条目 →

  4. 1.0.52026-11-17

    • 任务看板支持后台持续巡检、排期和结果产物查看。
    • 插件中心新增教训库、会话接棒和成绩单。
    • 路由图展开与筛选更清楚，同级应用不再随刷新跳位。

    查看完整条目 →

  5. 1.0.42026-10-24

    • 用量页显示三方应用自己的名字，不再借用 OpenCode 等内置应用。
    • 修复 Chat 接 Anthropic 上游时可选参数导致反复重试。
    • 上游安全拦截时返回原因，不再显示空回复。

    查看完整条目 →

  6. 1.0.32026-10-21

    • Windows 安装包现在包含订阅功能，装好即可直接登录。
    • macOS 通用包补上订阅组件，Intel 与 Apple 芯片都可用。

    查看完整条目 →

  7. 1.0.22026-10-21

    • 新增订阅引擎：登录订阅账号后，模型直接进入资源池参与路由。
    • 新增三方应用接入：Command Code、Crush、Droid、Kimi Code、AtomCode、OmO 以令牌接入网关，应用节点可重新签发令牌或删除应用。
    • 新增 System One 决策协议入口，按组路由决策请求。

    查看完整条目 →

  8. 1.0.12026-10-19

    • 路由页改成一行一个应用，点开就能设路由、新建路由组。
    • 路由组可以混装不同协议的模型，任何一个应用都能直接用。
    • 侧边栏列出全部可路由应用，用得少的默认折叠，随时展开。

    查看完整条目 →

  9. 1.0.02026-10-14

    • PHI 1.0 正式发布：把 AI 编程工具接进同一套本地网关。
    • 在一处管理 Claude Code、Codex 等应用的供应商配置。
    • 用量统计新增「会话」和「上下文」两个面板。

    查看完整条目 →
