1.1.0

2026-11-22
  • 任务看板新增智能体视图：一行一个智能体，第一行是与 Router 的讨论区。
  • 智能体定义扩展为「它是谁、负责什么、能使用什么、怎样算完成」，派发时编译进启动指令。
  • 添加智能体时和 Router 多轮对话起草，左侧对话、右侧定义，任意版本可切回继续聊。
  • 智能体与 Router 都有头像，点一下即可更换。
  • 任务详情页可直接与 Router 讨论需求，结论写回卡片，Router 给出的表单能在对话里直接填写提交。
  • 讨论与执行互斥：讨论卡不参与自动派发；已完成的卡可「重新讨论」派生带背景的新一轮。
  • 卡片可指派给某个智能体，指派与开工分开；派发时记录智能体快照，历史不随配置变化。
  • 修复拖拽经过行与建议卡片因透明度写法不生效而缺失的底色。
