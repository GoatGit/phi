更新日志

1.0.2

2026-10-21
  • 新增订阅引擎：登录订阅账号后，模型直接进入资源池参与路由。
  • 新增三方应用接入：Command Code、Crush、Droid、Kimi Code、AtomCode、OmO 以令牌接入网关，应用节点可重新签发令牌或删除应用。
  • 新增 System One 决策协议入口，按组路由决策请求。
  • 路由图的应用列默认最多显示五个，其余收进「展开」。
  • 用量记录按三方应用区分来源，不再混成一个笼统类型。
  • 订阅登录回调显示 PHI 自己的页面，不再是别的品牌。
